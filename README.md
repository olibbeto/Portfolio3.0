## 🔥 Portfolio 3.0 — Built Different

> **No heavy frameworks. No Webflow. Pure HTML5 · CSS3 · Vanilla JavaScript · Three.js · Firebase**

| Feature / Effect | What it does |
|------------------|-------------|
| 🔴 **Three.js Interactive Scene** | Wireframe 3D geometric fragments that react to your mouse in real time |
| 💬 **Live Visitor Guestbook** | Real-time comment board powered by Firebase Realtime Database with input sanitization |
| 🗂️ **Dynamic Category Filter** | Instant multi-category filtering (`All`, `Web`, `3D / WebGL`, `Desktop`, `Games`) |
| 🖥️ **Browser Showcase Mockup** | Custom macOS-style browser chrome framing with live status indicators |
| 🃏 **Perspective 3D Card Tilt** | Physics-based card tilt with dynamic specular shine following the cursor |
| 🧲 **Magnetic Buttons** | Interactive CTAs that physically attract and chase the user's cursor |
| 🌊 **Parallax Depth & Scanlines** | Smooth multi-layered Z-axis depth and animated cyber scanlines |
| 💀 **Chromatic Glitch Typography** | Split-channel chromatic glitch effect with high-contrast text |
| 🔮 **Floating Skill Orbs** | 3D glowing tech stacks — click or hover to inspect and trigger 360° spin |
| 🌓 **Adaptive Dual Theme** | Cyberpunk dark HUD mode and clean, high-contrast light mode |
